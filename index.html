⑥Reflection — สิ่งที่ทำจริงและบทเรียน

ปัญหาที่เจอ → วิธีแก้

  • Apify Web Scraper ติด Forbidden (403) กับ Wongnai — เปลี่ยนไปใช้ Browse AI robot ที่เทรนไว้ แล้วดึงผ่าน REST API ด้วย Bearer token แทน
  • n8n Merge node ค้าง เพราะ 2 branch แบบ parallel รอกันไม่จบ — ปรับ flow เป็น sequential เส้นเดียว แล้วให้ Clean node อ้างอิงข้อมูลข้าม node ด้วย $('Node').all() ใน memory
  • HTTP Request ยิงซ้ำตามจำนวน input items (80 ครั้ง) — เปิด Execute Once ใน node settings
  • Google Sheets append สะสมซ้ำทุกรอบ test จน Read ค้างที่ 12,800 แถว — เคลียร์ sheet และตัด Read node ที่ไม่จำเป็นออกจาก chain

ข้อจำกัด & สิ่งที่ได้เรียนรู้

  • ข้อจำกัดข้อมูล: บางร้านจาก Google Maps ไม่มีพิกัด/ช่วงราคา ทำให้ S4 ใช้ค่าประมาณจากชื่อทำเล และ Wongnai จำกัดที่ 40 ร้านต่อ listing
  • คะแนนอ่อนไหวต่อความครบของข้อมูล — ร้านที่จับคู่ได้ 2 แหล่ง (เช่น ครัวดอกไม้ขาว) ได้เปรียบ S5 อย่างมีนัยสำคัญ ซึ่งสะท้อนความน่าเชื่อถือจริง
  • AI แนะนำผิดแล้วแก้ยังไง: AI เคยแนะ actor ที่ใช้ไม่ได้กับ free plan — ตรวจ error message จริง อ่าน docs ของ Browse AI แล้วเปลี่ยน auth format จนผ่าน
  • นำไปใช้ต่อ: pattern "scrape → raw → clean → score → report" reuse ได้กับงานเปรียบเทียบ vendor/partner ของทีม Integration ทันที
